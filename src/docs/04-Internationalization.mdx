# 🌍 Internationalization (i18n)

Zaman supports multiple locales and calendar systems out of the box, with built-in support for Persian (Jalali) and Gregorian calendars.

## 🚀 Quick Start

### Switching Locales

```tsx
import { DatePicker } from 'zaman'

// Persian Calendar (Jalali/Shamsi)
<DatePicker locale="fa" direction="rtl" />

// English Calendar (Gregorian)
<DatePicker locale="en" direction="ltr" />
```

---

## 🗓️ Calendar Systems

### Jalali Calendar (Persian/Shamsi)

The Jalali calendar is the official calendar in Iran and Afghanistan.

```tsx
<DatePicker locale="fa" direction="rtl" />
```

**Features:**

- 12 months with Persian names (فروردین, اردیبهشت, etc.)
- Solar calendar (more accurate than Gregorian)
- Week starts on Saturday
- Persian numerals (۰۱۲۳...)

### Gregorian Calendar

The internationally used calendar.

```tsx
<DatePicker locale="en" direction="ltr" />
```

**Features:**

- Standard 12 months (January, February, etc.)
- Week starts on Sunday or Monday
- Western numerals (0123...)

---

## 🔤 Text Direction

### RTL (Right-to-Left)

For languages like Persian, Arabic, Hebrew:

```tsx
<DatePicker direction="rtl" />
```

### LTR (Left-to-Right)

For languages like English, Spanish, French:

```tsx
<DatePicker direction="ltr" />
```

### Auto-Detection

Locale and direction are often paired:

```tsx
// Persian → RTL
<DatePicker locale="fa" direction="rtl" />

// English → LTR
<DatePicker locale="en" direction="ltr" />
```

```tsx

  defaultLocale: 'ar'
})

```

## 🎨 Locale Data Structure

### Complete Type Definition

```tsx
interface LocaleData {
  code: string // Locale code (e.g., 'en', 'fa')
  name: string // Display name
  direction: 'rtl' | 'ltr' // Text direction
  calendar: 'jalali' | 'gregorian' // Calendar system

  weekDays: Array<{
    key: number // 0-6 (Sunday to Saturday)
    name: string // Full name
    short: string // Abbreviated name
  }>

  months: Array<{
    key: number // 1-12
    name: string // Month name
  }>

  labels: {
    today: string
    selectDate: string
    selectTime: string
    confirmDate: string
    cancel: string
    year: string
    month: string
    day: string
    hour: string
    minute: string
    am: string
    pm: string
  }
}
```

## 🌐 Multi-Language App Example

### Language Switcher

```tsx
import { useState } from 'react'
import { DatePicker } from 'zaman'

function MultiLanguageApp() {
  const [language, setLanguage] = useState<'fa' | 'en'>('en')

  const direction = language === 'fa' ? 'rtl' : 'ltr'

  return (
    <div dir={direction}>
      <select
        value={language}
        onChange={(e) => setLanguage(e.target.value as 'fa' | 'en')}
      >
        <option value="en">English</option>
        <option value="fa">فارسی</option>
      </select>

      <DatePicker locale={language} direction={direction} />
    </div>
  )
}
```

### With i18n Library Integration

```tsx
import { useTranslation } from 'react-i18next'
import { DatePicker } from 'zaman'

function IntegratedApp() {
  const { i18n } = useTranslation()

  // Map your i18n locale to zaman locale
  const zamanLocale = i18n.language === 'fa' ? 'fa' : 'en'
  const direction = i18n.dir()

  return <DatePicker locale={zamanLocale} direction={direction} />
}
```

## 📅 Date Formatting

### Format Patterns

Customize how dates are displayed:

```tsx
<DatePicker customShowDateFormat="DD/MM/YYYY" locale="en" />
```

### Common Patterns

| Pattern       | Example     | Description     |
| ------------- | ----------- | --------------- |
| `YYYY/MM/DD`  | 2024/01/15  | ISO format      |
| `DD/MM/YYYY`  | 15/01/2024  | European        |
| `MM/DD/YYYY`  | 01/15/2024  | American        |
| `YYYY-MM-DD`  | 2024-01-15  | Dash separator  |
| `DD MMM YYYY` | 15 Jan 2024 | With month name |

### Persian Date Formats

```tsx
<DatePicker customShowDateFormat="YYYY/MM/DD" locale="fa" />
// Output: ۱۴۰۲/۱۰/۲۵
```

## 🎯 Best Practices

### 1. Match Locale with Direction

```tsx
// ✅ Good - Consistent
<DatePicker locale="fa" direction="rtl" />
<DatePicker locale="en" direction="ltr" />

// ❌ Bad - Inconsistent
<DatePicker locale="fa" direction="ltr" />
```

### 2. Set Document Direction

```tsx
function App() {
  const [locale, setLocale] = useState('en')
  const direction = locale === 'fa' ? 'rtl' : 'ltr'

  return (
    <div dir={direction}>
      <DatePicker locale={locale} direction={direction} />
    </div>
  )
}
```

### 3. Provide Language Selection

```tsx
// Let users choose their preferred language
<select onChange={(e) => setLocale(e.target.value)}>
  <option value="en">English</option>
  <option value="fa">فارسی</option>
</select>
```

### 4. Store User Preference

```tsx
function App() {
  const [locale, setLocale] = useState(() => {
    return localStorage.getItem('locale') || 'en'
  })

  useEffect(() => {
    localStorage.setItem('locale', locale)
  }, [locale])

  return <DatePicker locale={locale} />
}
```

## 🌟 Advanced Examples

### Multi-Calendar Display

```tsx
import { Calendar, CalendarProvider } from 'zaman'

function MultiCalendar() {
  return (
    <CalendarProvider>
      <div style={{ display: 'flex', gap: '2rem' }}>
        <div>
          <h3>Gregorian</h3>
          <Calendar locale="en" direction="ltr" />
        </div>

        <div>
          <h3>جلالی</h3>
          <Calendar locale="fa" direction="rtl" />
        </div>
      </div>
    </CalendarProvider>
  )
}
```

### Dynamic Locale from URL

```tsx
import { useSearchParams } from 'react-router-dom'

function LocalizedDatePicker() {
  const [searchParams] = useSearchParams()
  const locale = searchParams.get('lang') === 'fa' ? 'fa' : 'en'
  const direction = locale === 'fa' ? 'rtl' : 'ltr'

  return <DatePicker locale={locale} direction={direction} />
}
```

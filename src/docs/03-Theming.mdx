# 🎨 Theming Guide

Zaman provides a powerful, flexible theming system that lets you customize every aspect of the components' appearance.

## 🚀 Quick Start

### Method 1: Inline Props (Simplest)

The quickest way to customize appearance:

```tsx
<DatePicker accentColor="#FF6B6B" round="x3" locale="en" direction="ltr" />
```

### Method 2: ThemeProvider (Recommended)

For consistent theming across your app:

```tsx
import { ThemeProvider, createTheme, DatePicker } from 'zaman'

const myTheme = createTheme({
  colors: {
    primary: {
      DEFAULT: '#8B5CF6',
      light: '#A78BFA',
      dark: '#7C3AED'
    }
  },
  round: 'thick'
})

function App() {
  return (
    <ThemeProvider theme={myTheme}>
      <DatePicker />
    </ThemeProvider>
  )
}
```

## 📏 Spacing System

Control dimensions and spacing:

```tsx
const theme = createTheme({
  spacing: {
    calendarItemWidth: '40px',
    calendarItemHeight: '40px',
    calendarGap: '8px',
    headerHeight: '48px',
    modalPadding: '16px'
  }
})
```

### Available Spacing Properties

| Property             | Default  | Description                  |
| -------------------- | -------- | ---------------------------- |
| `calendarItemWidth`  | `'40px'` | Width of calendar day cells  |
| `calendarItemHeight` | `'40px'` | Height of calendar day cells |
| `calendarGap`        | `'8px'`  | Gap between calendar items   |
| `headerHeight`       | `'48px'` | Height of calendar header    |
| `modalPadding`       | `'16px'` | Padding inside modal         |

## 🔘 Border Radius

### Using Presets

```tsx
<DatePicker round="x3" />
```

Available presets:

- `thin` - Minimal rounding
- `x1` - Small
- `x2` - Medium
- `x3` - Large
- `x4` - Extra large
- `thick` - Maximum

### Custom Radius

```tsx
const theme = createTheme({
  radius: {
    item: '8px', // Calendar items
    modal: '16px', // Modal/popup
    button: '6px', // Buttons
    input: '8px' // Input fields
  }
})
```

### Round Preset Reference

```tsx
import { roundPresets } from 'zaman'

// roundPresets contains:
{
  thin: { item: '2px', modal: '4px', button: '2px', input: '4px' },
  x1: { item: '4px', modal: '8px', button: '4px', input: '6px' },
  x2: { item: '6px', modal: '12px', button: '6px', input: '8px' },
  x3: { item: '8px', modal: '16px', button: '8px', input: '10px' },
  x4: { item: '10px', modal: '20px', button: '10px', input: '12px' },
  thick: { item: '12px', modal: '24px', button: '12px', input: '16px' }
```

## 🔧 Advanced Theming

### Merging Themes

Combine themes or extend the default:

```tsx
import { mergeTheme, defaultTheme } from 'zaman'

const myTheme = mergeTheme(defaultTheme, {
  colors: {
    primary: {
      DEFAULT: '#8B5CF6'
    }
  }
})
```

### Runtime Theme Updates

```tsx
function ThemeSwitcher() {
  const [isDark, setIsDark] = useState(false)

  const theme = isDark ? darkTheme : lightTheme

  return (
    <ThemeProvider theme={theme}>
      <button onClick={() => setIsDark(!isDark)}>Toggle Theme</button>
      <DatePicker />
    </ThemeProvider>
  )
}
```

## 🎯 Theming Best Practices

### 1. Use ThemeProvider for Consistency

```tsx
// ✅ Good - Consistent theming
<ThemeProvider theme={myTheme}>
  <DatePicker />
  <Calendar />
  <TimePicker />
</ThemeProvider>

// ❌ Bad - Inconsistent styling
<DatePicker accentColor="#FF0000" />
<Calendar accentColor="#00FF00" />
```

### 2. Define Theme Constants

```tsx
// theme.ts
export const appTheme = createTheme({...})

// Use in components
import { appTheme } from './theme'
```

### 3. Extend, Don't Replace

```tsx
// ✅ Good - Extends default
const theme = mergeTheme(defaultTheme, {
  colors: { primary: {...} }
})

// ⚠️ Be careful - Replaces everything
const theme = createTheme({
  colors: { primary: {...} }
  // Missing other required properties!
})
```

### 4. Use Semantic Color Names

```tsx
// ✅ Good
colors: {
  weekend: '#EF4444',
  disabled: '#9CA3AF'
}

// ❌ Less clear
colors: {
  weekend: '#EF4444',
  thing: '#9CA3AF'
}
```

## 📱 Responsive Theming

Adjust theme based on screen size:

```tsx
function ResponsiveTheme() {
  const [isMobile, setIsMobile] = useState(false)

  useEffect(() => {
    const checkMobile = () => {
      setIsMobile(window.innerWidth < 768)
    }
    checkMobile()
    window.addEventListener('resize', checkMobile)
    return () => window.removeEventListener('resize', checkMobile)
  }, [])

  const theme = createTheme({
    spacing: {
      calendarItemWidth: isMobile ? '36px' : '42px',
      calendarItemHeight: isMobile ? '36px' : '42px'
    }
  })

  return (
    <ThemeProvider theme={theme}>
      <DatePicker />
    </ThemeProvider>
  )
}
```

## 🎭 What is Zaman?

**Zaman** (زمان) is Persian for "Time". It's a modern, accessible, and feature-rich date and time picker library built for React applications. Whether you're working with Jalali (Persian/Shamsi) or Gregorian calendars, Zaman has you covered.

## 📦 Components Overview

Zaman provides four main components:

### 1. **DatePicker**

The most common use case - a text input with a popup calendar. Perfect for forms and data entry.

### 2. **Calendar**

A standalone calendar component for inline display. Great for dashboards and date visualization.

### 3. **TimePicker**

A dedicated time selection component with support for both 12-hour and 24-hour formats.

### 4. **CalendarProvider**

A context provider for managing calendar state across multiple components.

## 🚀 Quick Start

Get up and running in seconds:

```bash
# Install with your favorite package manager
npm install zaman
# or
yarn add zaman
# or
pnpm add zaman
```

```tsx
import { DatePicker } from 'zaman'

function App() {
  return (
    <DatePicker onChange={(date) => console.log('Selected:', date.value)} />
  )
}
```
